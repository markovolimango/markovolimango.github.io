RISC-V Kernel

Jun. 2026
C C++ RISC-V assembly

A small operating system kernel for RISC-V. Started as the Operating Systems course project and extended well beyond it.

  • Preemptive multithreading with per-thread kernel stacks and a timer-driven context switch written in RISC-V assembly.
  • O(1) priority scheduler over per-priority active and expired queues, with semaphores for blocking and wakeup.
  • User/supervisor mode privilege separation with an ecall system call interface.
  • Boundary-tag heap allocator where one metadata block serves as both a chunk's footer and the next chunk's header, giving O(1) coalescing on free.
  • Debugged with GDB against QEMU, running in Docker.

Logo Language Server

Apr. 2026
Java LSP

A language server for the Logo programming language, with a VS Code client.

  • One-way pipeline architecture (lexer, recursive descent parser, analysis), with lsp4j types confined to the protocol boundary.
  • A user-defined arity map, built during parsing, resolves calls in a language with no argument delimiters.
  • Symbol resolution over a scope tree that stores definitions in order and searches in reverse, so redefinitions resolve to the latest binding.
  • Debounced reparsing, syntax highlighting, go-to declaration/definition/references, rename, document structure, diagnostics, completion, hover and folding ranges.

A Unix-style shell built as a university project.
